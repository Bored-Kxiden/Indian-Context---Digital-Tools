# Notes for Claude Code sessions

- **Read `CONTEXT.md` first.** It records the project's context, decisions, assumptions, open questions, and change log.
- **Update `CONTEXT.md` in the same commit as any change** to content, structure, design, hosting, or decisions. Add a change-log entry (newest first) and, for new decisions, an ID in section 4.
- **Do not push to `main` unless the owner asks.** `main` deploys to production on Vercel. Work on the feature branch you were given.
- The repository is public. Keep personal emails, tokens, and private links out of it.
- Never invent research data. Examples must be labelled illustrative.
- Commands: `npm run dev`, `npm run build`. Regenerate cards with `npm run build:templates`.
